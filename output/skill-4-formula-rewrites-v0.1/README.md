## Skill 4 v0.1 公式速查

### 标题（5 类）
- **A 数字结果型**：`[反差点1]➡[反差点2]｜[结果]！附[方案]`
- **B 反常识断言型**：`[反常识判断]！` 或 `[物品+超预期属性]！`
- **C 痛点+方案型**：`[反常识归因]才是[症状]根源❗️[方案]（[人群]）`
- **D 政策/红利型**：`[权威事件]！[人群] [红利] 已来！！`（感叹号轰炸）
- **E 教程/SOP 型**：`[极致效率词]！[教程/SOP]，[人群限定]`

### Hook（3 类）
- **A 反常识断言**：第一句打碎预期
- **B 数字冲击**：反差点数字开场
- **C 痛点共鸣**：直接喊出读者心里话

### 结构（3 类）
- **A 痛点+方案 干货文**（最普适）
- **B 数字对比 故事文**（最冲击）
- **C 反常识揭露 观点文**（最易爆）

### CTA（3 类）
- **A 互动型**：`评论区扣 [关键词]`
- **B 行动型**：`先 [动作]！错过 [惩罚]`
- **C 留钩型**：`下篇讲 [进阶]，先关注`
