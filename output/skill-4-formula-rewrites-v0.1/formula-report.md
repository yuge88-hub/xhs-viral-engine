### 02. 开头 Hook 公式（3 类）

#### Hook A: 反常识断言开场 ⭐⭐⭐⭐⭐
**范本**：
- "内脏脂肪才是肚子胖的根源"
- "正常人是做不好自媒体的"
- "野路子卖手机壳，年入3000万"

**公式**：
```
[反常识结论]！[读者震惊/质疑]？
今天就扒给你看。
```

**为什么有效**：第一句话打碎读者预期 → 制造认知冲突 → 不得不继续读。

---

#### Hook B: 数字冲击开场 ⭐⭐⭐⭐
**范本**：
- "大学做兼职确实过的很滋润了"
- "3年赚17万"
- "瘦了40斤换了种人生"

**公式**：
```
[反差点数字]，[身份/场景]
[第二行：第二个数字/结果]
[第三行：钩子——为什么能做到？]
```

**为什么有效**：数字是最直接的"价值证明"，读者第一秒就知道"这篇值得读"。

---

#### Hook C: 痛点共鸣开场 ⭐⭐⭐⭐
**范本**：
- "你公众号写了一周，还是没人看？"
- "你是不是也在用 AI 副业，但一分钱没赚到？"
- "肚子上的肉真的难瘦"

**公式**：
```
[读者具体痛点描述]
[第二行：放大痛点]
[第三行：反问——是不是你？]
```

**为什么有效**：直接喊出读者心里话 → "这说的就是我" → 立即停留。

### 03. 内容结构公式（3 类）

#### 结构 A: 痛点+方案 干货文（最普适）⭐⭐⭐⭐⭐
**模板**（来自 mimeng 干货文）：
```
[Hook: 反常识断言]（1-2行）

[痛点共鸣：你是不是也XX？]（3-4行）

01 [第一个方案]
   - 具体步骤 1
   - 具体步骤 2
   - [金句压底]

02 [第二个方案]
   - 具体步骤 1
   - 具体步骤 2
   - [金句压底]

03 [第三个方案]
   - 具体步骤 1
   - 具体步骤 2
   - [金句压底]

[CTA: 评论区扣数字 / 收藏 / 转发]
```

**为什么有效**：痛点→方案 1→方案 2→方案 3 是小红书最稳定的"信息密度"结构。读者读完能直接抄作业。

---

#### 结构 B: 数字对比 故事文（最冲击）⭐⭐⭐⭐
**模板**：
```
[Hook: 反差数字]

[背景：我曾经/我朋友/我读者 是什么样的状态]
[转折：直到我做了一件事]
[方法：具体3步]
[结果：数字对比]

[金句压底]
```

**范本**：`130➡️90｜瘦了40斤换了种人生！附饮食➕运动`
**为什么有效**：用具体数字讲故事 → 真实感 → 可信度 → 收藏。

---

#### 结构 C: 反常识揭露 观点文（最易爆）⭐⭐⭐⭐
**模板**：
```
[Hook: 反常识断言]

[案例 1: 具体的"以为是这样"]
[案例 2: 实际"是这样"]
[案例 3: 实际"是这样"]

[金句：为什么大家都被骗了]
[CTA: 评论区告诉我...]
```

**范本**：`正常人是做不好自媒体的`
**为什么有效**：立场鲜明 → 引发争议 → 评论暴涨 → 算法推流。

**核心洞察**：5 个跨关键词痛点可以归纳为 **3 个元痛点**：

1. **"效果存疑"**（不知道是不是真的 / 怀疑是割韭菜）
2. **"个体差异"**（我可能不适合 / 体质不同 / 情况特殊）
3. **"门槛/成本"**（不会外语 / 没时间 / 要花 7880 学费）

## 跨关键词规律总结（5 关键词 1 条公式）

| 元素 | 普适规律 |
|---|---|
| **标题** | 必须含数字 / 反常识 / 痛点中的至少 1 个 + 1 个 emoji 或 ❗️ |
| **Hook** | 必须在 100 字内出现反常识判断 / 数字 / 痛点共鸣 |
| **结构** | 01/02/03 干货文最稳，反常识揭露文最爆 |
| **CTA** | 评论区扣数字 > 收藏号召 > 关注留钩子 |
| **标签** | 9 个 tag = 1 个大词 + 2 个中词 + 3 个长尾 + 3 个场景/情绪词 |
| **长度** | 正文 300-500 字最佳（手机 3-5 屏） |
