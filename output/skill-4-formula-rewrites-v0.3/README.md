## 🚀 使用方法

### 最简调用

```powershell
cd "C:\Users\张哥\Downloads\web-clipper-master"
python skills\skill-4-viral-rewriter\rewriter.py `
  --keyword "AI 副业" `
  --pain "切记，真能赚钱的不会和你说的" `
```

## 🛠️ 下一步：填骨架

每个 demo 文件都是**填空式骨架**，下一步：

1. 用编辑器打开 `.md` 文件
2. 把 `[TODO: ...]` 替换成你的具体内容
3. 参考文件内嵌的 v0.1 仿写片段（已有完整句式示范）
4. 按 mimeng 自检清单过一遍
5. 复制到 xhs 发布

**填完 1 条约 5-10 分钟**（vs 30 分钟从零写）。
