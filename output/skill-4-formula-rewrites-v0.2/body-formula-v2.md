# v0.2 Body 公式（3 个可复用模板）

> **来源**：从 v0.1 5 条仿写反推
> **方法**：抽象出"结构 + 情绪节奏 + 段落功能"3 维模板
> **覆盖**：xhs 80%+ 干货文爆款

---

## 模板 A：「N 个真相/元凶/底层逻辑」（反常识揭露型）

**适用场景**：求证型 (V) 痛点 + 吐槽型 (C) 痛点
**情绪节奏**：打脸 → 颠覆 → 重塑
**段落数量**：5-7 段

### 结构

```
[Hook: 反常识断言 / 数据冲击]（2-3 行）
空行
[痛点放大: 引用高赞评论佐证]（2-3 行）
空行

01 [第 1 个真相/元凶]
   - 现象描述（1 行）
   - 案例/数据（1-2 行）
   - 情绪金句压底（1 行）
空行

02 [第 2 个真相]
   ... 同上
空行

03 [第 3 个真相]
   ... 同上
空行

[转折: "真相 X：不是不能做，是..."]（可选）
空行

[CTA: 评论区扣关键词 / 转发给朋友]（2-3 行）
```

### 段落功能表

| 段落 | 功能 | 字数 | 情绪 |
|---|---|---|---|
| Hook | 颠覆预期 | 30-50 | 震惊/质疑 |
| 痛点放大 | 引发共鸣 | 30-50 | 愤怒/共鸣 |
| 01-0N 真相 | 论证 + 案例 | 100-150/段 | 理性 + 情绪 |
| 转折 | 重塑认知 | 30-50 | 释然/希望 |
| CTA | 行动触发 | 30-50 | 急迫/邀请 |

### 范本
- v0.1 AI 副业 仿写（5 个真相）
- v0.1 副业赚钱 仿写（3 个底层逻辑）

### 仿写骨架（填空式）

```markdown
[标题: N 个 [被忽视/没人说/颠覆] 的 [领域] [真相/元凶]！]

[Hook: 反常识结论]！

你是不是也 [痛点共鸣]？

[引用 1 条高赞痛点评论佐证]。

今天扒给你看！🔥

01 [真相 1: 反常识归因]
   [具体现象 + 数据/案例]
   [情绪金句]

02 [真相 2: 颠覆认知]
   ...

03 [真相 3: 重新定义]
   ...

[CTA: 评论区扣关键词 / 转发给朋友]
```

## 模板 B：「N 种人/体质的专属方案」（分群干货型）

**适用场景**：犹豫型 (H) 痛点（"我这种行不行"）
**情绪节奏**：共鸣 → 自测 → 方案 → 安心
**段落数量**：6-8 段

### 结构

```
[Hook: 反常识发现]（2 行）
空行
[痛点共鸣: 引用高赞评论]（2-3 行）
空行
[反问: 是不是你？]（1-2 行）
空行

[自测: N 个症状]（3-5 行 bullet）
空行

01 [类型 1 名称]
   - 自测症状（1-2 条）
   - 错的做法（1-2 行）
   - 正确做法（3-4 个 bullet）
   - 情绪金句
空行

02 [类型 2 名称]
   ... 同上
空行

03 [类型 3 名称]
   ... 同上
空行

[警告: 顺序错了 = 补错]（1-2 行）
空行
[CTA: 评论区告诉我你的类型 / 收藏]（2-3 行）
```

### 段落功能表

| 段落 | 功能 | 字数 | 情绪 |
|---|---|---|---|
| Hook | 颠覆预期 | 30-50 | 震惊 |
| 痛点共鸣 | 引发共鸣 | 30-50 | 委屈/无力 |
| 自测 | 拉近距离 | 50-80 | 好奇 |
| 01-0N 类型 | 分类 + 方案 | 150-200/段 | 理性 + 安心 |
| 警告 | 强化记忆 | 30-50 | 紧张 |
| CTA | 行动触发 | 30-50 | 邀请 |

### 范本
- v0.1 营养食疗 仿写（3 种体质）
- v0.1 减肥 仿写（3 个元凶）

### 仿写骨架（填空式）

```markdown
[标题: 同样 [动作]，为什么 [结果不一样]？N 种 [人/体质] 的专属方案！]

[Hook: 反常识发现]！

[痛点共鸣 + 引用评论]。

[反问: 是不是你？]

自测一下：
- [症状 1]
- [症状 2]
- [症状 3]
（如有 3 条 → ...）

01 [类型 1]
自测：
- [症状 A]
- [症状 B]
[错的做法]
[正确做法: 3-4 个 bullet]
[金句]

02 [类型 2]
... 同上

03 [类型 3]
... 同上

[警告: 顺序/搭配错了 = 灾难]

[CTA: 评论区告诉我你的类型]
```

## 模板 C：「N 个红利/机会/政策窗口」（政策红利型）

**适用场景**：求带型 (B) 痛点 + 犹豫型 (H) 痛点
**情绪节奏**：震撼 → 羡慕 → 拆解 → 行动
**段落数量**：7-9 段

### 结构

```
[Hook: 数据冲击 + 羡慕评论]（3-4 行）
空行
[反问: 真传一句话，假传万卷书]（2 行）
空行
[承诺: 今天不教你月入过万，只教...]（2-3 行）
空行

01 [红利 1]
   - 为什么是红利（数据/算法变化）
   - 3 个必杀技（具体动作）
   - 情绪金句
空行

02 [红利 2]
   ... 同上
空行

... 0N ...

[总结: N 个真相]（1-2 行）
空行
[CTA: 评论区扣赛道 / 关注下篇]（2-3 行）
```

### 段落功能表

| 段落 | 功能 | 字数 | 情绪 |
|---|---|---|---|
| Hook | 数据 + 羡慕 | 30-50 | 震撼 |
| 反问 | 引发好奇 | 30-50 | 期待 |
| 承诺 | 建立信任 | 30-50 | 安心 |
| 01-0N 红利 | 拆解 + 方法 | 100-150/段 | 理性 + 兴奋 |
| 总结 | 强化记忆 | 30-50 | 满足 |
| CTA | 行动触发 | 30-50 | 急迫 |

### 范本
- v0.1 自媒体 仿写（5 个新政策红利）

### 仿写骨架（填空式）

```markdown
[标题: [权威平台/年份] [N] 个 [新政策/红利/机会]！[人群限定] 怎么接住？]

[Hook: 震撼数据 + 引用羡慕评论]
[反问: 真传一句话...]
[承诺: 今天不教你 X，只教...]

01 [红利 1 名称]
[为什么是红利: 数据/算法变化]
[3 个必杀技: 具体动作]
[金句]

02 [红利 2]
...

[总结: N 个真相]
[CTA: 评论区扣你的赛道]
```

## 3 模板覆盖度验证

| 模板 | 覆盖 v0.1 仿写 | 占比 |
|---|---|---|
| A 反常识揭露 | AI 副业 + 副业赚钱 | 40% |
| B 分群干货 | 营养食疗 + 减肥 | 40% |
| C 政策红利 | 自媒体 | 20% |

**结论**：3 模板覆盖 5/5 v0.1 仿写，**任意新选题 = 选 1 模板填空**。

---

## 模板选择决策树

```
你的核心痛点是？
├─ V 求证型 / C 吐槽型 → 模板 A
├─ H 犹豫型（个体差异） → 模板 B
└─ B 求带型（求方法） + 时机红利 → 模板 C
```
